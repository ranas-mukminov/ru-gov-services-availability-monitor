# Antigravity Style Guide

## Code Style
- **Python**: Follow PEP 8. Use `black` and `ruff` for formatting and linting.
- **Type Hints**: Use type hints for all function arguments and return values.
- **Structure**: Keep functions small and focused. Use classes where appropriate for state management.
- **Async**: Use `asyncio` for I/O bound operations (network requests).

## Testing
- **Framework**: Use `pytest`.
- **Coverage**: Aim for high test coverage, especially for core logic.
- **TDD**: Write tests before implementing features.
- **Determinism**: Tests must be deterministic and fast. Avoid external network calls in tests (use mocks).

## Security
- **No Secrets**: Never commit secrets or API keys to the repository.
- **Validation**: Validate all external input (config files, API requests).
- **Passive Monitoring**: Strictly adhere to passive monitoring principles. No load testing, no scraping, no auth bypass.
- **Dependencies**: Regularly check dependencies for vulnerabilities (`pip-audit`).

## AI Agent Guidance
When editing this repo, always:
- Keep tests green.
- Add or update tests together with each feature or fix (aim for TDD).
- Prefer secure, explicit, and maintainable solutions over clever hacks.
- Preserve legal and ethical constraints: no stress tests, no evasion tooling.
