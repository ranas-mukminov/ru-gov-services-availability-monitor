# Безопасность и Правовые Аспекты

## Ограничения системы

Система `ru-gov-services-availability-monitor` разработана исключительно для **пассивного наблюдения**.

### Что система ДЕЛАЕТ:
- Выполняет периодические HTTP GET/HEAD запросы к публичным адресам.
- Проверяет валидность SSL/TLS сертификатов.
- Измеряет время ответа (latency).

### Что система НЕ ДЕЛАЕТ:
- Не выполняет нагрузочное тестирование (stress testing).
- Не пытается обойти механизмы защиты (WAF, captcha).
- Не собирает персональные данные.
- Не использует уязвимости.

## Ответственность оператора

> **ВАЖНО**: Оператор системы несет полную ответственность за соблюдение законодательства РФ и условий использования (Terms of Use) мониторируемых сервисов.

1. **Rate Limiting**: Настраивайте интервалы проверок разумно (не чаще 1 раза в 5-10 минут для одного сервиса), чтобы не создавать нагрузку.
2. **Robots.txt**: Уважайте правила `robots.txt` целевых ресурсов.
3. **Согласование**: Для корпоративного использования рекомендуется уведомить владельцев ресурсов или использовать только публично декларируемые API/статус-страницы, если таковые имеются.

## Безопасность кода

- В репозитории не должно быть захардкоженных секретов.
- Все внешние данные (конфиги, ответы API) проходят валидацию.
